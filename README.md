# speedtest

Консольный скрипт на Python: замеряет скорость скачивания по заданному URL.

Скрипт делает **10 последовательных запросов** к адресу, каждый раз дожидаясь
полного ответа, и печатает среднее время запроса, общий объём данных и скорость.

## Требования

- Python 3.9+
- Внешние библиотеки не нужны (только стандартная библиотека)

## Запуск

```bash
python3 speedtest.py <URL>
```

Пример (лучше брать тяжёлый файл — от нескольких МБ):

```bash
python3 speedtest.py https://example.com/big-image.jpg
```

Пример вывода:

```
Запрос  1/10: 5242880 Б за 0.412 с
...
Среднее время запроса: 0.405 с
Всего скачано: 52428800 Б (52.43 МБ)
Скорость скачивания: 103.60 Мбит/с (12.95 МБ/с)
```

## Единицы измерения

- Скорость выводится в **Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит) —
  так обычно указывают тарифы провайдеров. Дополнительно показана **МБ/с**
  (мегабайты в секунду, 1 МБ = 1 000 000 байт).
- Формула: `общий объём (байты) × 8 / суммарное время всех запросов (с) / 1 000 000`.
- Время — в секундах, объём — в байтах.

## Обработка ошибок

При некорректном URL или сетевой ошибке скрипт печатает сообщение в stderr и
завершается с ненулевым кодом.
